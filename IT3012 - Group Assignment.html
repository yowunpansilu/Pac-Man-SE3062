How search works here. Every algorithm follows the same graph-search skeleton; only the fringe changes.
  1. Put the start state on the fringe.
  2. Pop a node from the fringe. If its state is the goal, return the path of actions that reached it.
  3. If its state has not been expanded before, mark it expanded and push each successor (with the extended path, and accumulated cost where relevant) onto the fringe.
  4. Repeat until the goal is found or the fringe is empty (return failure).
DFS → util.Stack (LIFO)  |  BFS → util.Queue (FIFO)  |  UCS & A* → util.PriorityQueue (priority = g for UCS, g + h for A*).
